# Apply name aliases to AST nodes

Apply name aliases to AST nodes

## Usage

``` r
alias_ast_names(ast, alias_map, classes = NULL, ...)
```

## Arguments

- ast:

  An AST object or list.

- alias_map:

  A named list or character vector. Keys are aliases, values are
  original names.

- classes:

  Character vector of AST classes to filter (optional).

## Value

Modified AST with aliases applied.
