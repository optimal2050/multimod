# Create a new multimod_set object

Create a new multimod_set object

## Usage

``` r
new_multimod_set(name, desc = NULL, subset_of = NULL, data = NULL)
```

## Arguments

- name:

  Character. Name of the set.

- desc:

  Character. Description of the set (optional).

- subset_of:

  Character vector. Name of the parent set (optional).

- data:

  Optional values (e.g., character vector or data.frame).

## Value

An object of class `multimod_set`
