# Get a pair of brackets

This function returns a pair of brackets based on the input character.

## Usage

``` r
brackets_pair(x)
```

## Arguments

- x:

  A character string or vector of length 1 or 2. If the length is 1, it
  will return a pair of brackets based on the character. If the length
  is 2, it will return the two characters as a vector.

## Value

A character vector of length 2 containing the opening and closing
brackets.
