# Check if model or object is trimmed

Check if model or object is trimmed

## Usage

``` r
is_trimmed(x)
```

## Arguments

- x:

  Model object, or individual set/parameter/mapping/variable/equation

## Value

Logical indicating if trimmed

## Examples

``` r
if (FALSE) { # \dontrun{
is_trimmed(model)
is_trimmed(model$parameters$pDemand)
} # }
```
