# Parse indexed aggregation function (sum, prod, min, max)

Parse indexed aggregation function (sum, prod, min, max)

## Usage

``` r
parse_indexed_func(expr, func, symbols, depth, max_depth)
```

## Arguments

- expr:

  Character string

- func:

  Function name

- symbols:

  Symbol table

- depth:

  Current depth

- max_depth:

  Maximum depth

## Value

AST node or NULL
