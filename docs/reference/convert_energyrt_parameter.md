# Convert energyRt parameter to multimod format

Convert energyRt parameter to multimod format

## Usage

``` r
convert_energyrt_parameter(ert_param, orig_param = NULL, inMemory = FALSE)
```

## Arguments

- ert_param:

  An energyRt parameter object

- orig_param:

  Original multimod parameter structure (optional)

- inMemory:

  Logical. Embed data in-memory?

## Value

Updated parameter with data reference
