# Create a multimod model object

Create a multimod model object

## Usage

``` r
new_multimod_model(
  name = NULL,
  desc = NULL,
  sets = list(),
  aliases = list(),
  mappings = list(),
  parameters = list(),
  variables = list(),
  equations = list()
)
```

## Arguments

- desc:

- sets:

  named list of sets

- mappings:

  named list of mappings

- parameters:

  named list of multimod_parameter objects

- variables:

  named list of multimod_variable objects

- equations:

  named list of multimod_equation objects
