# Build a list of symbols from model_info

Build a list of symbols from model_info

## Usage

``` r
build_symbols_list(model_info)
```

## Arguments

- model_info:

  model_structure object (as returned by
  [`read_gams()`](https://optimal2050.github.io/multimod/reference/read_gams.md))

## Value

A list containing sets, mappings, parameters, and variables.
