# Convert GAMS-style sum/prod to GMPL binding syntax

Convert GAMS-style sum/prod to GMPL binding syntax

## Usage

``` r
as_gmpl_sum_prod(x, ...)
```

## Arguments

- x:

  A func AST node representing sum or prod

- ...:

  Additional arguments passed to as_gmpl

## Value

GMPL sum/prod expression with proper binding
