# Resolve an alias name to its base set name

Resolve an alias name to its base set name

## Usage

``` r
resolve_alias_to_set(alias_name, model)
```

## Arguments

- alias_name:

  Character string of the alias (e.g., "r", "y", "yy")

- model:

  Model object containing aliases

## Value

Base set name (e.g., "REGION", "YEAR") or the original name if not found
