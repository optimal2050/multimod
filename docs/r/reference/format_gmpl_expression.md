# Format GMPL expression with line breaks and indentation

Format GMPL expression with line breaks and indentation

## Usage

``` r
format_gmpl_expression(gmpl_lines, indent = 2, ...)
```

## Arguments

- gmpl_lines:

  Character vector of GMPL code lines

- indent:

  Number of spaces for indentation

- ...:

  Additional arguments (not used)

## Value

Formatted character vector
