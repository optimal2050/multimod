# multimod: Define and Render Mathematical Models Across Modeling Languages

A unified framework for mathematical model representation, analysis,
transformation, and optimization. Uses an intermediate representation to
construct, import, inspect, simplify, and export mathematical models
independently of modeling languages and solvers. Reads 'GAMS' and 'GNU
MathProg' models; writes 'GAMS', 'GNU MathProg', 'JuMP', 'Pyomo' and
'LaTeX'; generates and reduces linear programming matrices for solving
with 'HiGHS' or 'cuOpt', and decodes the solutions. Currently focused on
continuous linear optimization.
