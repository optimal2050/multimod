# multimod: Define and Render Mathematical Models Across Modeling Languages

A unified framework for mathematical model representation, analysis,
transformation, and optimization. Uses a universal intermediate
representation (IR) to construct, import, inspect, simplify, and export
mathematical models independently of modeling languages and solvers.
Supports 'GAMS', 'GNU MathProg', 'JuMP', 'Pyomo', and 'LaTeX', direct
generation and reduction of linear programming (LP) matrices, solving
with 'HiGHS', 'cuOpt', and solution decoding. Currently focused on
continuous linear optimization.
