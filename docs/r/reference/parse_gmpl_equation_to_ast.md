# Parse GMPL Equation to Multimod Equation

Convert model_structure equation to multimod equation format

## Usage

``` r
parse_gmpl_equation_to_ast(eqn_info, symbols = list())
```

## Arguments

- eqn_info:

  List containing equation information (name, body, sense, dims,
  condition)

- symbols:

  Symbol table for context

## Value

multimod equation object
