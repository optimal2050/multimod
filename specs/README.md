# Cross-language specifications

This directory holds the language-neutral contract between the
implementations of multimod. It is not part of the R package build.

## Source of truth

The AST schema is generated by the R package and shipped with it as
`../inst/schema/multimod-ast-v1.json`. It is not duplicated here; other
implementations vendor it from that path at build time.

## Matrix goldens

`goldens/matrix/<case>/` holds the LP that the matrix route assembles from a
model, as plain tables:

```
rows.csv       i, name, sense, lo, up          one row per LP row
cols.csv       j, name, lo, up, obj            one row per LP column
triplets.csv   i, j, coef                      nonzeros, sorted by (i, j)
meta.json      dims, nnz, objective symbol and sense, known optimum
presolve/      the same after the doubleton presolve, plus eliminated.csv
               (col, ref, coef, pass) and a `full` column giving each kept
               row's and column's position in the full LP
```

Doubles are printed at 17 significant digits; infinities as `Inf` and `-Inf`;
labels are `symbol[i1,i2,...]`, or the bare symbol for a scalar. Cases: `toy`
(`example_models$toy`) and `utopia` (the energyRt model on the TOPIA R7 kit,
`example_models$energyRt$multimod`).

They are written by R and replayed by every implementation of the matrix
route, including the R package itself
(`tests/testthat/test-matrix-goldens.R`): a build must reproduce them exactly
in structure and to 1e-12 in values. Regenerate after an intended change of
the assembly with

```sh
Rscript specs/goldens/generate.R
```

A larger local model is covered the same way when `MULTIMOD_GOLDEN_MODEL_DIR`
names a workspace written by `save_model()`; its goldens are written under
that directory and stay out of the repository.
