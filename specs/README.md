# Cross-language specifications

This directory is reserved for the language-neutral contract between the
implementations of multimod. It holds only this note until the native core
work starts (see [`../core/`](../core/README.md)).

## Source of truth

The AST schema is generated by the R package and shipped with it as
`../inst/schema/multimod-ast-v1.json`. It is not duplicated here; other
implementations vendor it from that path at build time.

## Planned contents

```
specs/
├── goldens/
│   ├── generate.R        # Rscript specs/goldens/generate.R, via pkgload
│   ├── ast/              # model_to_json() of every model in example_models
│   └── render/           # as_gams(), as_gmpl(), as_jump(), as_pyomo(),
│                         # as_latex() of the toy model, one file per language
└── README.md
```

The goldens are generated by R and replayed by the other implementations.
They are the gate files of the core port: a stage is complete when its output
is byte-identical to the corresponding golden. The R tests do not read them.
