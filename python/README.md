# multimod for Python (planned)

This directory is reserved for the Python binding of multimod. It is empty
apart from this note.

The binding is not written by hand from the R code. multimod moves to one
native core (see [`../core/`](../core/README.md)); R and Python then become
thin bindings over the same implementation, sharing the AST, the JSON schema
(`../inst/schema/multimod-ast-v1.json`), the readers, the code generators and
the matrix route. The Python package appears here when the core skeleton
exists.

## Planned layout

```
python/
├── pyproject.toml        # wheels built from the core
├── src/multimod/         # the binding, with py.typed
├── tests/                # pytest; goldens replayed from ../specs/
└── README.md             # becomes the home page of docs/python/
```

The documentation site of the binding is generated by
`../tools/site/python_reference.py` from the R reference structure in
`../_pkgdown.yml`, and built with MkDocs into `../docs/python/`. The site
build skips this step while `pyproject.toml` is absent.
